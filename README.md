# betterf3

A client-side Fabric mod for Minecraft 1.21.11.

Press **Right Shift** in-game to open the betterf3 menu. Click the gear (settings)
to rename the menu and change its color. Your choices are saved to
`config/betterf3.json`.

## How to get the .jar (built automatically by GitHub)
1. Upload the CONTENTS of this folder to a new GitHub repository.
2. Open the **Actions** tab. A build starts on its own (takes a few minutes).
3. Open the finished run, scroll to **Artifacts**, download **Artifacts**.
4. Unzip it. `betterf3-1.0.0.jar` is your mod.

Drop that jar into `.minecraft/mods` on a Fabric 1.21.11 profile,
alongside Fabric API (https://modrinth.com/mod/fabric-api).
